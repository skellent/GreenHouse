Skell's GreenHouse V3.0

Un invernadero autonomo que observa, decide y registra.

GreenHouse integra sensores ambientales, ESP32-S3, camara e inteligencia artificial para ayudar a monitorear cultivos en tiempo real desde una app movil.

Monitoreo vivo Datos, camara, IA e historial CSV.
Capacidades

Del sensor a una decision util

01

Sensores completos

Temperatura, humedad, luz, altura y estado del hardware se consultan desde la API local del ESP32-S3.

02

IA integrada

La app muestra intensidad UV, riego, ventilacion y perfil de planta activo para entender la respuesta del sistema.

03

Camara y evidencia

Captura fotografias con doble solicitud para evitar frames cacheados y exporta historial completo en CSV.

Aplicacion movil

Hecha para el WebView de Capacitor

La interfaz movil se construye en HTML, CSS y JavaScript vanilla, sin framework de UI, para empaquetarse directamente dentro de Android.
